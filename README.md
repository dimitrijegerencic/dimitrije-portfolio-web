# dimitrije-portfolio-web

Vue 3 and Nuxt UI Portfolio for Dimitrije Gerencic

Built with [Nuxt 4](https://nuxt.com), [Nuxt UI](https://ui.nuxt.com) and Tailwind CSS.

## Setup

Requires Node 24 (see `.nvmrc`) and pnpm.

```bash
nvm use
pnpm install
pnpm dev        # http://localhost:3000
```

## Scripts

```bash
pnpm build      # production build
pnpm preview    # preview production build
pnpm lint       # ESLint
pnpm typecheck  # vue-tsc
```
